# 王嘉溪 · AIGC 作品集

视频创作与 AIGC 设计作品集，包含个人简介、31 个项目及视频与设计混合交互作品球。

- 首页作品球：26 条视频记录与 36 张设计图，共 62 张卡片。
- 全部设计与过程图为压缩 WebP，包含 52 页 PDF 展示内容。
- 原版节奏开场影片已内置，支持作品筛选、图片放大、资料编辑与备份导出。

## 作品视频

开场影片已内置。26 条作品原片暂未提供线上链接，当前可查看其封面及项目资料；在编辑器中填入 B 站完整链接或视频直链可替换为在线播放。
